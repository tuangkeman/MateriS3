Konsep Inti AI: Knowledge Base + Inference Mechanism

Gambar puzzle di slide: dua potongan berbeda bentuk, terpisah, tapi hanya bermakna kalau menyatu. Inilah kerangka berpikir hampir semua modul, termasuk Tugas 1 dan 2.

Alur kerja sistem cerdas

1. Knowledge Base (KB)

Sumber kecerdasan sistem. Isinya: konsep, teori, prosedur praktis beserta hubungannya, dan fakta tentang objek di domain terpilih beserta relasinya. Syarat: harus dikumpulkan, dikodekan, dan diatur secara sistematis supaya bisa dipakai mesin.

Cara membuatnya (knowledge engineering): identify the task → knowledge acquisition (kumpulkan pengetahuan relevan, mis. dari pakar) → knowledge representation (ubah ke bentuk formal: logika, rule IF-THEN, semantic network, frame).

2. Inference Mechanism

Program yang menalar memakai KB untuk menarik kesimpulan. Dua teknik utamanya: search (menelusuri ruang kemungkinan: BFS, DFS, A*, dst) dan pattern matching (mencocokkan fakta dengan pola, mis. kondisi IF pada rule atau premis pada logika, lalu menerapkan Modus Ponens/resolution).

Tanpa KB, mesin inferensi tidak punya bahan. Tanpa mesin inferensi, KB hanya data diam.

Kenapa dikatakan terpisah tapi saling terkait?

  • Terpisah: pengetahuan (apa) dan cara menalar (bagaimana) dibuat sendiri-sendiri. KB bisa ditambah atau diperbarui tanpa menulis ulang mesin inferensi, dan satu mesin bisa dipakai untuk banyak KB.
  • Terkait: bentuk KB harus cocok dengan jenis inferensinya. KB berupa graph/tree cocok dengan search; KB berupa rule cocok dengan pencocokan pola (forward chaining); KB berupa logika cocok dengan aturan inferensi.

Contoh utuh: sistem rating lomba

KB: 9 rule (job < 15 → performa buruk, dst). Input: fakta job=20, usia=3, tujuan=serius. Inferensi: pattern matching mencocokkan fakta dengan IF → Rule 2 menyala (performa baik) → Rule 5 (mahir) → Rule 9 → output festival internasional. Menyalakan rule berantai ini disebut forward chaining.
Contoh lain: navigasi mobil. KB = peta sebagai Point dan Path (semantic network). Inferensi = search jalur terpendek (A*). Output = rute.

Hubungan dengan teori lain di modul

  • DIKW: data → information → knowledge → wisdom. KB berisi level knowledge, yaitu informasi yang sudah diberi konteks. Inferensi inilah yang menaikkan data menjadi keputusan (Autonomy).
  • Readable data & different interpretation: manusia membaca teks dengan makna, mesin hanya membaca simbol. Karena itu pengetahuan harus dibuat formal (sintaks dan semantik jelas) supaya mesin tidak salah tafsir. Itulah gunanya knowledge representation dan ontologi.
  • Jenis pengetahuan: declarative (fakta), procedural (aturan), heuristic (rule of thumb seperti h(n)), meta, structural. Semuanya bisa menjadi isi KB.
  • Informed search: heuristik h(n) adalah pengetahuan domain yang disuntikkan ke mesin inferensi agar search lebih efisien.
Kaitan ke Tugas: Tugas 1 butir proses (karakteristik fungsional) dan Tugas 2 butir 3 (rancangan mekanisme inferensi) pada dasarnya meminta Anda menjawab dua hal: apa isi KB sistem Anda, dan mesin inferensi apa yang menalar di atasnya.

Introduction to AI

Automatic

Input (trigger) → aturan pra-set → output (aksi). Input sama, aturan sama, output selalu sama.

Autonomy

Sistem merasakan, memutuskan, bertindak, dan belajar dari umpan balik.

Definisi AI

  • McCarthy (Dartmouth, 1955): setiap aspek belajar atau fitur kecerdasan lain pada prinsipnya dapat dideskripsikan begitu tepat sehingga mesin dapat mensimulasikannya.
  • Turing (1947): yang kita inginkan adalah mesin yang dapat belajar dari pengalaman.

Multiple Intelligence (Gardner, 1983)

Logis-matematis (number smart), linguistik (word), visual-spasial, musikal, kinestetik (body), interpersonal (people), intrapersonal (self), naturalis (nature). Dasar argumen interdisipliner.

DIKW

Data–Information = Automatic; Knowledge–Wisdom = Autonomy.

Roadmap AI

Pesan modul: Embrace AI, jadilah orang yang cerdas dan adaptif, never stop learning.

Problem Solving & Uninformed Search

Problem solving manusia = proses search

Elemen: Problem state (situasi/initial state), Goal (bisa lebih dari 1), Operator (prosedur pindah state). Ruang masalah direpresentasikan sebagai graph atau tree.

Informed Search

Heuristic

Dari Yunani heuriskein (menemukan): aturan praktis untuk menyelesaikan masalah kompleks secara efisien. Fungsi heuristik memuat wawasan domain; tujuannya mengevaluasi state dan memandu pencarian. f(n) memetakan state n ke angka x.
(+) heuristik bagus meng-expand lebih sedikit node; (−) biaya menghitungnya bisa mahal.

g(n)

Biaya historis (accumulated cost) dari simpul awal ke n. Fungsi objektif: ukuran aktual, mahal.

h(n)

Biaya estimasi dari n ke goal. Perkiraan, bisa tidak akurat, murah.
f(n) = g(n) + h(n) (total biaya evaluasi). Contoh slide: f(B)=g(SAB)+h(B)=1+2+1=4; f(C)=g(SBAC)+h(C)=2+2+1+1=6.

Best First (Greedy)

Selalu expand node terbaik menurut h(n); backtracking boleh. Algoritma seperti BFS, tetapi setelah menambah path baru, seluruh QUEUE diurutkan berdasarkan h(n).

A* = tiga prinsip

Branch & Bound: branching (bangkitkan cabang), bounding (LowerBound = biaya path lengkap pertama), selection (pilih node jika biayanya < LowerBound, selain itu hapus). Pelajaran: hapus partial path berbiaya lebih tinggi. Contoh: goal pertama berbiaya 5 → LowerBound=5, node berbiaya 5 dan 6 dibuang.
Redundant path deletion: jika ada path P dan Q yang sama-sama menuju node I dan cost_P ≥ cost_Q, hapus P.
Metode A*: seperti Best First, queue diurutkan dengan f(n)=g(n)+h(n) ditambah penghapusan path redundan.

SMA* (Simplified Memory-Bounded A*)

Berjalan seperti A*; saat memori penuh, buang leaf terburuk (f terbesar). Expand leaf terbaik yang terbaru, hapus leaf terburuk yang terlama.

Local Search: Hill Climbing

Tanpa backtracking, successor function tetap. Mulai dari satu solusi → perbaiki berulang → sampai nilai maksimal (naik bukit sampai puncak). Analogi: robot = algoritma, bukit = ruang pencarian, altimeter = fungsi objektif, bukit tertinggi = global optimum, bukit lain = local optimum.

Algoritma HC (Moore)

X = konfigurasi awal; E = Eval(X). Loop: hitung Eval semua move di moveset; jika semua ≤ E, berhenti dan kembalikan X; kalau tidak ambil move terbaik, X = move itu, E = nilainya.

Contoh TSP 4 kota (A,B,C,D)

Operator = tukar posisi (kombinasi): C(4,2)=6 → Switch 1,2 / 2,3 / 3,4 / 4,1 / 2,4 / 1,3. Contoh: ABCD dengan Switch 1,2 → BACD. Tabu list = daftar closed node agar tidak diulang.
JenisProsedur
Simple HCBangkitkan node (satu per satu), buang yang sudah pernah, ambil node pertama yang lebih baik dari sebelumnya.
Steepest AscentBangkitkan semua node, buang yang pernah, ambil yang terbaik dibanding semua.
Random-RestartUlangi HC dari state awal acak sebanyak N kali, simpan hasil terbaik. Tujuan: lolos dari local maxima, plateau, dan ridge.

Pseudocode RRHC

best ← None; ulang N kali: state ← acak; hasil ← HillClimbing(state); jika hasil lebih baik dari best → best ← hasil; return best

Optimization Search

Simulated Annealing (SA)

Meniru annealing (pemanasan lalu pendinginan terkendali pada logam). Dua kunci: proses "mengguncang" dan energi. Panas tinggi = energi besar, makin dingin energi turun.
Penerimaan: energi lebih rendah = lebih baik. Jika WSE < CSE → CS=WS. Jika tidak: P = exp(−ΔE/T), ΔE = WSE−CSE, ambil acak R ∈ [0,1]; jika P > R terima WS, selain itu tolak. Solusi terbaik = CS.
Pendinginan: Ti+1 = α·Ti (α<1). Contoh T0=120, α=0,25 → 30 → 7,5 → 1,875; berhenti jika Ti < Tend(=2).
Masalah: proses acak, makan waktu, belum tentu optimal. Aplikasi: path generation, rekonstruksi citra, penjadwalan, layout sirkuit, routing, deteksi objek, desain filter digital.

Genetic Algorithm (GA)

Meniru evolusi alam (Darwin: seleksi alam + pewarisan genetik). Inspirasi biologis: sel → kromosom (46 = 23 pasang) → DNA (A,T,G,C) → gen (unit pewarisan). Mitosis = sel menggandakan kromosom lalu membelah jadi dua sel identik.
  • Kromosom = untai variabel yang merepresentasikan satu solusi; gen = satu parameter (mis. bit); fitness = kualitas kromosom; populasi = kumpulan individu.
Seleksi: elitist/truncation, tournament, roulette wheel. Stop: jumlah iterasi tertentu atau populasi konvergen (Diff = δf/f < k).
Crossover (jika PC > Pc(Si)): tukar segmen dua kromosom, tidak membuat materi baru tetapi kromosom baru (single-point / multi-point). Mutasi (jika PM > Pm(Si)): ubah acak gen, menghasilkan materi baru dan mengguncang populasi.
Parameter: popsize, PC, PM, generasi. Masalah: premature convergence (diversitas kurang → perbesar populasi / restart); No-Free-Lunch: tidak ada metode optimal untuk semua masalah, gunakan pengetahuan masalah. Aplikasi: optimasi, search, penjadwalan.

Adversarial Search

Untuk permainan kompetitif multi-player zero-sum (untung satu pihak = rugi pihak lain, tidak ada win-win). Peran: strategic thinking, tujuan bertentangan, pengambilan keputusan, state-space search (pohon), dasar game playing (catur, Go, checkers, poker).

Minimax

Meminimalkan kerugian maksimum (minmax) atau memaksimalkan keuntungan minimum (maxmin), bekerja mundur dari akhir permainan. Syarat: 2 pemain, MAX (komputer) dan MIN (lawan), deterministik, informasi sempurna.

Alpha-Beta Pruning

Mengurangi jumlah node yang dievaluasi minimax. Alpha = nilai sementara node MAX (hanya boleh naik); Beta = nilai sementara node MIN (hanya boleh turun). Jika nilai MIN sudah lebih kecil dari nilai MAX induknya, tidak perlu menghitung lebih lanjut (pruning). Contoh slide: 11 evaluasi dihemat.

Knowledge Representation

Knowledge base berisi konsep, teori, prosedur, fakta tentang objek domain beserta relasinya; harus dikumpulkan, dikodekan, dan diatur sistematis; dipakai inference mechanism untuk bernalar. Knowledge engineering: identify task → knowledge acquisition → knowledge representation.
IS (deskriptif, diagnostik) → ML (prediktif, preskriptif) → AI (kognitif).

Logika

Penalaran deduktif (umum → khusus, verifikasi) dan induktif (khusus → umum, penemuan). Jenis: propositional (T/F), predicate (fakta, objek, relasi), temporal, probability (derajat keyakinan), fuzzy (derajat kebenaran).
  • Propositional: proposisi = pernyataan benar/salah. Konektor AND (∧), OR (∨), NOT (¬), IMPLIES (⇒), EQUIVALENT (⇔) dengan tabel kebenaran.
  • Modus Ponens: ((p⇒q) ∧ p) ⇒ q. Aturan lain: And-Elimination, And-Introduction, Or-Introduction, Double-Negation, Unit Resolution, Resolution.
  • Predicate: pecah menjadi predikat dan argumen, mis. in(car, garage), give(Berto, Orel, apple). Kuantor: ∀ (universal), ∃ (eksistensial).

List & Tree

Mewakili pengetahuan hierarkis. List: deretan item berperingkat. Tree: node = objek/kejadian, arc = relasi.

Semantic Network & Conceptual Graph

Node = konsep, arc = relasi (is-a, owns, works-for). Mencari jawaban = menelusuri arc maju/mundur dari node awal (mis. human_being(Kay)?). Tidak ada himpunan relasi standar. Contoh: navigasi mobil, Point(titik1, 36.59, 48.23), Path(jalur6, [titik6, titik7], 596.25, 30, 50). Conceptual graph: concept, relationship, type:referent.

Production System (IF kondisi THEN aksi)

Contoh slide (lomba): job <15/tahun → performa buruk; ≥15 → baik; usia <2 → pemula; usia ≥2 dan buruk → pemula; usia ≥2 dan baik → mahir; pemula+senang-senang → festival lokal; pemula+serius → nasional; mahir+senang-senang → nasional tahunan; mahir+serius → internasional.

Frame

Cocok untuk pengetahuan kompleks: node punya struktur dalam. Slot (atribut) + filler (nilai/prosedur), mendukung inheritance (class → superclass → instance, mis. ZE vehicle → Electric vehicle → Car → Van → Ford Ecostar).

Ontologi

Filsafat tentang "ada": essence vs existence (centaur punya essence, tidak exist). Di CS: spesifikasi formal, eksplisit dari konseptualisasi bersama (Gruber & Borst, 1998). Standar: RDF, OWL, SKOS. Kategori (Lassila & McGuinness): dari catalog/ID, glosarium, thesauri, is-a, frame, sampai batasan logika umum.

TUGAS 1 · Proposal sistem AI untuk SDG

Butir 1-3: Topik, SDG, Deskripsi masalah

Ditanyakan: pilih satu kasus nyata, kaitkan dengan minimal satu SDG, jelaskan masalahnya.

Modul: 03 (problem formulation: problem state, goal, operator; combinatorial explosion) dan 02 (Automatic vs Autonomy, definisi AI).

Konsep: Masalah dalam kacamata AI selalu punya tiga hal: kondisi sekarang (initial state), kondisi yang diinginkan (goal), dan tindakan yang boleh dilakukan (operator). Alasan memakai AI: masalah itu butuh pencarian atau keputusan yang tidak bisa dijawab aturan tetap (sistem Automatic: input sama, output selalu sama). Kalau ruang kemungkinannya besar, pencarian buta kewalahan (combinatorial explosion), jadi perlu AI.

Bentuk jawaban: konteks nyata dan siapa terdampak → kondisi sekarang → target → kenapa sulit diselesaikan manual/aturan biasa → hubungan jelas ke target SDG tertentu. Dinilai dari kejelasan dan ketepatan.

Butir 4: Karakteristik fungsional (input, output, proses)

Ditanyakan: apa yang dilakukan sistem: masuk apa, diolah bagaimana, keluar apa.

Modul: 02 (Autonomy: persepsi → keputusan → aksi → belajar; DIKW; slide AI Concepts; IS-ML-AI), 08 (KB), 03-07 (metode untuk proses).

Konsep: Input = data dari lingkungan (tingkat Data pada DIKW). Proses = knowledge base + mekanisme inferensi (search dan pattern matching) yang mengubah data menjadi informasi, pengetahuan, lalu keputusan. Output = keputusan/rekomendasi/aksi. Sistem disebut Autonomy bila ada umpan balik yang membuatnya memperbaiki diri. Catatan: modul hanya menyebut machine learning di peta IS-ML-AI, detailnya tidak dibahas.

Bentuk jawaban: tiga bagian terpisah. Input: jenis, sumber, format data. Proses: kelompok metode (search / optimasi / rule-based) beserta alasan. Output: bentuk dan siapa pemakainya. Sebutkan feedback loop bila ada.

Butir 5: Argumentasi interdisipliner

Ditanyakan: kenapa membangun sistem ini butuh bidang ilmu selain informatika.

Modul: 02 (definisi McCarthy, Multiple Intelligence Gardner), 08 (knowledge acquisition dari pakar, ontologi sebagai konseptualisasi bersama). Soal CPMK juga menyebut ilmu kognitif.

Konsep: AI = mesin yang mensimulasikan aspek kecerdasan manusia (McCarthy). Karena yang ditiru adalah kecerdasan, kamu butuh ilmu yang memahaminya (kognitif/psikologi), pakar domain sebagai sumber isi knowledge base, dan bidang yang terkait SDG (mis. kesehatan, lingkungan, ekonomi).

Bentuk jawaban: 3-4 disiplin; untuk tiap disiplin tulis kontribusinya ke sistem dan akibatnya bila diabaikan. Bukan sekadar daftar nama bidang.

Butir 6: Pertimbangan etika

Ditanyakan: bias, dampak sosial/lingkungan, privasi, transparansi.

Modul: hanya menyentuh sedikit: roadmap ANI/AGI/ASI (pekerjaan terdampak), slide AI-generated content, dan sifat KB yang eksplisit (lebih mudah dijelaskan). Selebihnya harus dari jurnal.

Konsep: Bias: data/aturan/KB yang tidak representatif menghasilkan keputusan tidak adil. Dampak sosial/lingkungan: siapa diuntungkan atau dirugikan, pekerjaan, energi. Privasi: data pribadi yang dikumpulkan dan disimpan. Transparansi: apakah keputusan bisa dijelaskan alasannya.

Bentuk jawaban: untuk tiap aspek: risiko yang spesifik di kasusmu, lalu cara mengurangi (mitigasi). Hindari kalimat umum yang berlaku untuk semua AI.

Butir 7: Daftar pustaka

Minimal 3 artikel ilmiah berkualitas (jurnal/konferensi), dipakai untuk mendukung masalah, metode, dan etika. Tidak berasal dari modul.

TUGAS 2 · Mekanisme inferensi untuk PAM

Butir 1: Formulasi/representasi masalah

Ditanyakan: ubah masalah PAM menjadi bentuk formal yang bisa diproses komputer.

Modul: 03 (elemen problem state, goal, operator; graph dan tree), 05 (contoh TSP: operator Switch, kombinasi), 07 (game tree), 08 (skema representasi: logical, procedural, networked, structured).

Konsep: Formulasi = menetapkan state, initial state, goal (atau fungsi objektif/heuristik, modul 04), operator, dan biaya. Representasi = cara menyimpannya. Bentuknya mengikuti jenis masalah: cari jalur → graph/tree; cari konfigurasi → state berupa susunan, operator berupa tukar/ubah; game → tree MAX dan MIN; sistem aturan → fakta dan rule IF-THEN.

Bentuk jawaban: daftar elemen formulasi lengkap + satu gambar/diagram representasi + alasan skema itu cocok. Dinilai dari ketepatan.

Butir 2: Proses kognitif yang dimodelkan

Ditanyakan: aktivitas berpikir manusia apa yang ditiru rancanganmu.

Modul: 03 (problem solving manusia: formulation → searching → execution), 02 (loop Autonomy, definisi AI, Gardner), 08 (jenis pengetahuan: declarative, procedural, heuristic, meta, structural; DIKW), 04 (heuristik = rule of thumb), 06 (SA meniru annealing dan GA meniru evolusi: contoh sistem yang meniru proses alamiah).

Konsep: Proses kognitif = rangkaian aktivitas mental: mengamati, mengingat pengetahuan, menalar/mencari, memutuskan, belajar. "Dimodelkan" berarti tiap aktivitas punya padanan komponen di sistemmu.

Bentuk jawaban: uraian proses berpikirnya + tabel dua kolom "aktivitas manusia → komponen sistem", dan sebutkan jenis pengetahuan yang dipakai.

Butir 3: Rancangan mekanisme inferensi

Ditanyakan: bagaimana sistem bernalar dari input sampai output (arsitektur, flowchart).

Modul: slide AI Concepts (KB + inference mechanism: search dan pattern matching); metode dari modul 03 (BFS/DFS/IDS), 04 (Best First, A*), 05 (hill climbing), 06 (SA, GA), 07 (Minimax, Alpha-Beta), 08 (forward chaining pada rule, logika).

Konsep: Mekanisme inferensi = prosedur sistematis yang menalar di atas KB dan input hingga menghasilkan kesimpulan. Pemilihan metode berdasarkan jenis masalah dan sifat algoritma (metrik modul 03: time, space, completeness, optimality), apakah ada heuristik, dan risiko terjebak local optimum (modul 05).

Butir 4: Contoh skenario eksekusi (trace)

Ditanyakan: satu contoh jalannya sistem melalui seluruh tahap, dari input hingga output.
