Jawaban UTS Infrastruktur LAN Bagian 2

1. Langkah-langkah Password Recovery pada Switch (tanpa kehilangan konfigurasi lama):
  1. Hubungkan PC ke port console switch, buka aplikasi terminal (PuTTY/Tera Term).
  2. Cabut kabel power switch, lalu colok kembali sambil menekan dan menahan tombol MODE hingga lampu LED port menyala dan berkedip.
  3. Lepaskan tombol MODE. Switch akan masuk ke mode switch: (boot loader).
  4. Ketik perintah flash_init lalu tekan Enter.
  5. Ubah nama file konfigurasi agar tidak diload saat booting: rename flash:config.text flash:config.old.
  6. Ketik boot untuk melanjutkan proses booting normal.
  7. Setelah masuk ke mode Switch>, ketik enable untuk masuk ke mode privileged EXEC (Switch#).
  8. Ubah kembali nama file konfigurasi tadi: rename flash:config.old flash:config.text.
  9. Load konfigurasi lama ke memori: copy flash:config.text system:running-config.
  10. Ganti password (misal: enable secret PasswordBaru).
  11. Simpan konfigurasi baru: copy running-config startup-config.
2. Tiga Metode Frame Forwarding pada Switch:
  1. Store-and-Forward: Switch menerima seluruh frame, memeriksa integritasnya menggunakan Frame Check Sequence (FCS), membuang frame jika ada error (CRC), lalu meneruskannya. (Metode default/rekomendasi Cisco).
  2. Cut-Through: Switch meneruskan frame segera setelah membaca alamat MAC tujuan (6 byte pertama). Tidak melakukan pengecekan error, sehingga memiliki latency paling rendah, tetapi bisa menyebarkan frame yang rusak.
  3. Fragment-Free: Modifikasi dari cut-through. Switch membaca 64 byte pertama frame sebelum meneruskannya. Tujuannya untuk menyaring runt frames (frame yang lebih kecil dari 64 byte akibat tabrakan/collision).
3. Tiga Masalah jika Redundancy tanpa STP (Spanning Tree Protocol):
  1. Broadcast Storm: Frame broadcast akan berputar terus-menerus di loop Layer 2 tanpa henti, membanjiri jaringan dan menghabiskan bandwidth.
  2. MAC Address Table Instability: Switch akan terus-menerus menerima frame yang sama dari port yang berbeda, menyebabkan tabel MAC terus berubah dan membingungkan switch.
  3. High CPU Utilization: Beban kerja switch meningkat drastis karena harus memproses dan meneruskan frame yang berputar-putar tanpa henti, yang bisa menyebabkan switch crash atau freeze.
4. Inter-VLAN Routing dan 3 Metodenya:

Pengertian: Proses meneruskan traffic jaringan dari satu VLAN ke VLAN lain menggunakan perangkat Layer 3 (Router atau Layer 3 Switch). Tanpa ini, host di VLAN berbeda tidak bisa berkomunikasi.

3 Metode:

  1. Legacy Inter-VLAN Routing: Menggunakan router dengan antarmuka fisik terpisah untuk setiap VLAN. (Kurang efisien karena butuh banyak port).
  2. Router-on-a-Stick: Menggunakan satu antarmuka fisik router yang dikonfigurasi menjadi beberapa subinterface (menggunakan trunking 802.1Q) untuk menangani banyak VLAN.
  3. Layer 3 Switch (SVI): Menggunakan Switch Virtual Interface (SVI) pada switch multilayer. Jauh lebih cepat karena routing dilakukan oleh hardware switch, cocok untuk jaringan skala besar.
5. Konfigurasi Membuat VLAN 10 dengan nama Mahasiswa:
Switch> enable
Switch# configure terminal
Switch(config)# vlan 10
Switch(config-vlan)# name Mahasiswa
Switch(config-vlan)# end
6. Konfigurasi Memasukkan Port Fa0/3 ke VLAN 20:
Switch> enable
Switch# configure terminal
Switch(config)# interface FastEthernet 0/3
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 20
Switch(config-if)# end
7. Lima Langkah Konfigurasi SSH pada Switch:
  1. Verifikasi dukungan SSH: show ip ssh.
  2. Konfigurasi nama domain IP: ip domain-name namadomain.com.
  3. Generate pasangan kunci RSA (mengaktifkan SSH): crypto key generate rsa (minimal 1024 bit).
  4. Buat user dan password lokal: username admin secret PasswordAman.
  5. Konfigurasi jalur VTY untuk menggunakan SSH:
    line vty 0 15
    transport input ssh
    login local
8. Konfigurasi Subinterface Fa0/1.20 (Gateway VLAN 20, IP 192.168.20.1/28):

(Catatan: /28 sama dengan subnet mask 255.255.255.240)

Router> enable
Router# configure terminal
Router(config)# interface FastEthernet 0/1.20
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.240
Router(config-subif)# exit
Router(config)# interface FastEthernet 0/1
Router(config-if)# no shutdown

(Jangan lupa mengaktifkan interface fisik utamanya dengan no shutdown)

9. Tiga Bagian Bridge ID (BID) pada Switch:
  1. Bridge Priority (Prioritas default: 32768).
  2. Extended System ID (ID VLAN, ditambahkan ke prioritas).
  3. MAC Address milik switch itu sendiri.
10. Empat Metode Pemberian IP DHCPv6 / IPv6 pada Jaringan:
  1. Manual: Konfigurasi IP address secara statis oleh administrator.
  2. SLAAC (Stateless Address Autoconfiguration) Only: Host membuat IP sendiri berdasarkan pesan RA (Router Advertisement) dari router (Flag A=1, O=0, M=0).
  3. SLAAC + Stateless DHCPv6: Host membuat IP sendiri via SLAAC, tapi mendapatkan info tambahan (seperti DNS) dari server DHCPv6 (Flag A=1, O=1, M=0).
  4. Stateful DHCPv6: Host mendapatkan IP address dan seluruh konfigurasi lainnya langsung dari server DHCPv6 (Flag A=0, O=0, M=1).
11. Tujuan Penerapan Per-VLAN Spanning Tree (PVST):

Untuk menjalankan instance STP yang terpisah untuk setiap VLAN. Ini memungkinkan adanya load balancing (penyeimbangan beban) karena root bridge untuk VLAN 10 bisa berbeda dengan root bridge untuk VLAN 20, sehingga jalur yang tadinya diblokir di satu VLAN bisa digunakan (forwarding) di VLAN lain.

12. Tujuan Implementasi EtherChannel pada Topologi Block Switch:

Untuk menggabungkan beberapa link fisik (kabel) menjadi satu link logis. Tujuannya adalah untuk meningkatkan bandwidth secara agregat, menyediakan redundansi (jika satu kabel putus, link tetap jalan), dan mencegah STP memblokir link redundan (karena STP melihat EtherChannel sebagai satu link logis tunggal).

13. Pengertian FHRP (First Hop Redundancy Protocol):

Mekanisme/protokol yang menyediakan default gateway cadangan (redundan) pada jaringan. FHRP memungkinkan dua atau lebih router berbagi satu IP Virtual dan MAC Virtual yang sama, sehingga jika router aktif (master/active) mati, router cadangan (standby) akan mengambil alih secara transparan tanpa membuat host kehilangan koneksi ke luar jaringan (mencegah single point of failure).

14. Cara Kerja HSRP (Hot Standby Router Protocol):
  1. Router dalam satu grup HSRP bertukar pesan Hello setiap 3 detik untuk memantau status.
  2. Satu router dipilih menjadi Active (meneruskan traffic) dan satu menjadi Standby (mengawasi).
  3. Pemilihan Active berdasarkan prioritas tertinggi (default 100). Jika prioritas sama, IP tertinggi menang.
  4. Jika router Active mati (tidak mengirim Hello selama 10 detik), router Standby akan naik menjadi Active dan mengambil alih IP & MAC Virtual.
15. Langkah Konfigurasi HSRP dan Gambar Topologi:

Langkah Konfigurasi (Dilakukan pada R1 dan R2):

  1. Masuk ke interface yang mengarah ke LAN: interface GigabitEthernet0/1 (contoh).
  2. Berikan IP Address fisik: ip address 192.168.1.2 255.255.255.0.
  3. Aktifkan interface: no shutdown.
  4. Konfigurasi HSRP grup 1 dan IP Virtual: standby 1 ip 192.168.1.254.
  5. (Opsional) Atur prioritas (R1 dibuat lebih tinggi): standby 1 priority 150.
  6. (Opsional) Aktifkan preempt agar langsung mengambil alih jika lebih tinggi: standby 1 preempt.

Gambar Topologi (Deskripsi Visual):

[ Internet / ISP ] | --------------------- | | [ R1 ] [ R2 ] (IP: 192.168.1.2) (IP: 192.168.1.3) (Priority 150) (Priority 100) (Active Router) (Standby Router) | | +---------+---------+ | [ Switch L2 ] | [ PC (Host) ] (IP PC: 192.168.1.10/24) (Default Gateway PC: 192.168.1.254)

Penjelasan Topologi: PC dikonfigurasi menggunakan IP Virtual 192.168.1.254 sebagai default gateway. R1 dan R2 secara fisik terhubung ke switch yang sama. Karena R1 memiliki prioritas lebih tinggi, R1 menjadi Active dan meneruskan paket dari PC. Jika R1 mati, R2 otomatis mengambil alih peran dengan IP Virtual yang sama.
