Catatan: Perintah Cisco dapat berbeda sesuai model perangkat. Gunakan hanya pada perangkat yang Anda berwenang kelola.
1Ketika seorang admin jaringan diberikan piranti switch yang sudah dikonfigurasi tetapi tidak mengetahui password untuk masuk dan mengedit konfigurasi, maka admin tersebut haruslah melakukan password recovery. Berikan langkah-langkah yang harus dikerjakan admin jaringan tersebut untuk bisa mengganti password piranti switch tersebut tanpa kehilangan konfigurasi lama yang sudah ada.
  1. Akses switch melalui kabel console dan restart.
  2. Masuk boot loader/ROMMON sesuai petunjuk model.
  3. Lewati sementara pemuatan startup-config sesuai prosedur resmi.
  4. Boot switch dan muat konfigurasi lama bila diperlukan.
  5. Ganti password, lalu simpan dengan copy running-config startup-config.

Ingat: jangan menghapus startup-config.

2Tuliskan tiga metode Frame Forwarding dalam proses Switching pada suatu switch, dan berikan sedikit penjelasan ringkas yang membedakan ketiganya.
  1. Store-and-Forward: menerima seluruh frame dan memeriksa CRC; lebih aman, lebih lambat.
  2. Cut-Through: meneruskan setelah membaca MAC tujuan; cepat, pemeriksaan error terbatas.
  3. Fragment-Free: memeriksa 64 byte pertama sebelum meneruskan; kompromi antara kecepatan dan pemeriksaan.
3Jelaskan 3 permasalahan yang akan muncul jika kita menggunakan model redundancy pada switch block design namun tidak menerapkan Spanning Tree Protocol!
  1. Layer 2 loop: frame berputar terus.
  2. Broadcast storm: broadcast membanjiri jaringan.
  3. MAC table instability: switch salah mempelajari lokasi MAC.
4Apakah yang dimaksud dengan inter-VLAN routing? Tuliskan 3 metode untuk melakukan inter-VLAN routing dan berikan penjelasan singkatnya.

Inter-VLAN routing adalah komunikasi antar-VLAN yang berbeda subnet.

  1. Router-on-a-stick: satu port router dengan beberapa subinterface trunk.
  2. Layer 3 switch: routing memakai SVI tiap VLAN.
  3. Router interface terpisah: tiap VLAN memakai interface fisik router sendiri.
5Tuliskan urutan perintah konfigurasi untuk membuat VLAN nomor 10 dengan nama Mahasiswa.
enable
configure terminal
vlan 10
name Mahasiswa
end
copy running-config startup-config
6Tuliskan urutan perintah konfigurasi untuk memasukkan port Fa0/3 suatu switch menjadi anggota VLAN 20.
enable
configure terminal
interface fa0/3
switchport mode access
switchport access vlan 20
end
copy running-config startup-config
7Tuliskan (5) lima langkah/perintah konfigurasi untuk mengkonfigurasi SSH pada switch dan mengaktifkannya sehingga switch bisa diakses secara remote.
enable
configure terminal
hostname SW1
ip domain-name kampus.local
username admin privilege 15 secret SandiKuat123!
crypto key generate rsa modulus 2048
ip ssh version 2
line vty 0 15
login local
transport input ssh
end
copy running-config startup-config

Switch juga perlu IP manajemen dan gateway yang sesuai. Ganti contoh password dengan password kuat.

8Tuliskan urutan perintah untuk konfigurasi subinterface fa0/1.20 untuk menjadi gateway vlan 20 dengan ip add 192.168.20.1/28 pada model router-on-a-stick inter-VLAN.
enable
configure terminal
interface fa0/1
no shutdown
exit
interface fa0/1.20
encapsulation dot1Q 20
ip address 192.168.20.1 255.255.255.240
no shutdown
end
copy running-config startup-config

Port switch menuju router harus trunk dan mengizinkan VLAN 20.

9Bridge ID suatu switch terdiri dari tiga bagian nomor, apa sajakah itu?
  1. Bridge priority.
  2. Extended System ID (ID VLAN).
  3. MAC address switch.
10Tuliskan 4 (empat) metode pemberian IP DHCPv6 pada piranti jaringan, berikan penjelasan untuk masing-masing metode.
  1. Stateful DHCPv6: server memberikan alamat IPv6.
  2. Stateless DHCPv6: alamat dibuat lewat SLAAC; DHCPv6 memberi info tambahan, misalnya DNS.
  3. SLAAC: host membuat alamat dari prefix Router Advertisement.
  4. Static: alamat diatur manual oleh administrator.
11Apakah tujuan penerapan per-VLAN spanning tree?

Menjalankan STP terpisah untuk setiap VLAN, sehingga root bridge dan jalur forwarding bisa diatur per VLAN sambil mencegah loop.

12Apakah tujuan dari implementasi Etherchannel dalam topologi block switch?

Menggabungkan beberapa link fisik menjadi satu link logis untuk menambah bandwidth, menyediakan redundansi, dan membantu load balancing.

13Apa yang dimaksud FHRP dalam konteks topologi ganda untuk mencegah single point failure?

First Hop Redundancy Protocol menyediakan default gateway virtual. Jika gateway aktif gagal, perangkat cadangan mengambil alih. Contoh: HSRP, VRRP, GLBP.

14Berikan penjelasan mengenai cara kerja HSRP?

Router berbagi IP virtual sebagai gateway. Router Active meneruskan trafik, router Standby siap menggantikan jika Active gagal. Hello digunakan untuk memantau status.

15Tuliskan langkah-langkah konfigurasi HSRP! Sertakan gambar topologi sesuai dengan langkah-langkah konfigurasi yang anda buat.

Topologi contoh: R1 Active (192.168.1.2), R2 Standby (192.168.1.3), gateway virtual 192.168.1.1. Semua terhubung ke LAN/VLAN yang sama.

R1 (Active)
enable
conf t
interface g0/0
ip address 192.168.1.2 255.255.255.0
standby 1 ip 192.168.1.1
standby 1 priority 110
standby 1 preempt
no shutdown
R2 (Standby)
enable
conf t
interface g0/0
ip address 192.168.1.3 255.255.255.0
standby 1 ip 192.168.1.1
standby 1 priority 100
standby 1 preempt
no shutdown

Verifikasi: show standby brief. Atur gateway PC ke 192.168.1.1. Uji failover dengan mematikan interface Active secara terkontrol.
