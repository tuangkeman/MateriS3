1. Stack

1.1 Definisi dan Istilah pada Stack

Struktur data linier dengan aturan khusus: penambahan dan pengambilan data hanya di satu posisi / ujung saja. Prinsipnya LIFO = Last In First Out (yang masuk terakhir, keluar pertama), seperti tumpukan piring.

PopMengeluarkan data paling atas
Top / PeekMelihat nilai paling atas tanpa mengeluarkannya
ClearMengosongkan isi Stack
Coba sendiri: Push 10, 20, 30, 40 lalu Pop. Yang keluar duluan pasti 40.

1.2 Implementasi Stack

Dengan List

Pakai list bawaan Python yang sudah efisien. Top bisa di depan atau belakang, tapi paling mudah di belakang: dua fungsi utamanya append dan pop. Class: StackList dengan atribut stack_data: list dan method __init__, push, pop, top, clear.

Dengan Linked List

Pakai class Linked List yang sudah dibuat sebelumnya. Susunan class: Node (data, next), SLNC (head, tail, size; method insert_head, delete_head), lalu StackLinkedList (stack_data: SLNC). Lebih mudah jika Top di head.

OperasiListLinked List (top di head)
Pushappend, O(1)insert head, O(1) (langkahnya selalu tetap)
Poppop, O(1)delete head, O(1). Jika top di tail: O(n)
Topindex -1, O(1)akses head/tail, O(1)
Clearclear, O(1)hapus Node satu per satu, O(n)
Kenapa top di head? Insert dan delete di head selalu butuh jumlah langkah tetap. Kalau top di tail pada singly linked list, pop harus menelusuri dari head dulu untuk menemukan node sebelum tail, makanya O(n).

2.2 Implementasi Queue

Penyimpanan bisa pakai List atau Linked List. Minimal ada tiga fungsi utama: enqueue, dequeue, front. Tambahan opsional: clear, __len__, dan __str__ untuk print.

Dengan List

Posisi Front terbaik di index 0. Enqueue memakai append(), dequeue mengambil elemen index 0 lalu menghapusnya (pop(0) atau del), dan front cukup mengakses index 0. Setiap method mengecek dulu apakah queue kosong, kalau kosong mengembalikan None.

class QueueList:
    def __init__(self):
        self.queue_data = list()
    def enqueue(self, new_data):
        self.queue_data.append(new_data)
    def dequeue(self):
        if len(self.queue_data) == 0:
            return None
        front_data = self.queue_data[0]   # ambil data terdepan
        del self.queue_data[0]            # lalu hapus
        return front_data
    def front(self):
        return None if len(self.queue_data) == 0 else self.queue_data[0]
    def clear(self):
        self.queue_data.clear()
    def __len__(self):
        return len(self.queue_data)
    def __str__(self):
        if len(self.queue_data) == 0:
            return 'Queue is empty'
        result = 'Queue contain ' + str(len(self.queue_data)) + ' data\n(Front) '
        for data in self.queue_data:
            result = result + ' ' + str(data)
        return result

Catatan tambahan (bukan dari slide): menghapus elemen index 0 pada list Python menggeser semua elemen sisanya, jadi dequeue di sini sebenarnya O(n).

Dengan Linked List

Head sebagai Front dan sebaiknya ada tail. Tanpa tail, enqueue (insert di belakang) harus menelusuri seluruh node dulu sehingga tidak efisien. Class: Node, SLNC (head, tail, size; delete_head, insert_tail), dan QueueLinkedList.

OperasiCaraKompleksitas
Enqueueinsert di tailO(1)
Dequeuedelete headO(1)
Frontakses data di headO(1)
from slnc import SingleLinkedListNonCircular
class QueueLinkedList:
    def __init__(self):
        self.queue_data = SingleLinkedListNonCircular()
    def enqueue(self, new_data):          # insert pada tail
        self.queue_data.insert_tail(new_data)
    def dequeue(self):                    # hapus head
        if len(self.queue_data) == 0:
            return None
        front_data = self.queue_data.head.data
        self.queue_data.delete_head()
        return front_data
    def front(self):
        if len(self.queue_data) == 0:
            return None
        return self.queue_data.head.data
    def __len__(self):
        return len(self.queue_data)
    def __str__(self):
        return str(self.queue_data)
    def clear(self):                      # dequeue sampai kosong
        while len(self.queue_data) > 0:
            self.dequeue()

2.3 Kasus-Kasus untuk Queue

Penggunaan Queue

Untuk kasus yang butuh pendekatan FIFO: penjadwalan resource oleh sistem operasi (CPU, disk, memori), spooling printer, buffer hardware input seperti keyboard, pengiriman paket data berurutan di jaringan, dan antrean pengiriman di mail/messaging server. Variasinya: Priority Queue (antrean berdasarkan skala prioritas) dan Deque (Double Ended Queue, punya dua ujung kepala).

Variasi Queue: Deque (Double Ended Queue)

Variasi Queue di mana enqueue dan dequeue bisa dari ujung kiri maupun kanan, jadi data bisa masuk dan keluar dari kedua ujung. Python sudah menyediakannya lewat import collections.

>>> dek = collections.deque()
>>> dek.append(20); dek.append(30)
>>> dek.appendleft(40); dek.appendleft(50)
>>> dek

Karakteristik: mutable, tambah data di awal dan akhir O(1), bisa bersifat LIFO maupun FIFO, bisa diakses dengan index, kompatibel dengan operator in, dan punya banyak fungsi bawaan. Dokumentasi: docs.python.org/3/library/collections.html#deque-objects

Sub-tree adalah bagian tree yang lebih kecil (misalnya subtree dari node B). Hubungan sebuah node dengan node satu level di bawahnya disebut Parent – Child.

Height dan Depth

Height tree = level maksimum. Pada tree contoh (A di level 0; B, C level 1; D, E, F level 2; G, H, I level 3) height-nya 3, dengan jumlah node per level 1, 2, 3, 3.
Height node = jarak terjauh node itu ke leaf-nya. Leaf (D, G, H, I) height 0; F punya leaf H dan I satu langkah di bawahnya, jadi height 1.
Depth node = jarak dari root ke node itu. Root A depth 0, F depth 2.
Cara mengingat: depth dihitung ke bawah dari root, height dihitung ke bawah menuju leaf (dari node itu sendiri). Klik node pada demo di atas untuk melihat keduanya.

Jenis-Jenis Tree

Binary Tree

Tiap node punya maksimal dua child, biasanya disimpan sebagai left dan right. Paling banyak dipakai dalam algoritma; variasinya: Binary Search Tree, AVL Tree, B-Tree, T-Tree. Binary tree yang lebih spesifik punya aturan peletakan child (kiri atau kanan).

3. Binary Search Tree (BST)

BST adalah binary tree dengan aturan: (1) child kiri nilainya lebih kecil dari parent, (2) child kanan lebih besar dari parent, (3) subtree kiri dan kanan juga harus memenuhi aturan 1 dan 2.
Jebakan saat mengecek “apakah ini BST?” Aturan berlaku untuk seluruh subtree, bukan hanya parent langsung. Contoh: node 19 sebagai child kanan 14 tampak benar (19 > 14), tetapi 19 berada di subtree kiri 18 sehingga harus lebih kecil dari 18, jadi tree itu bukan BST.

Kompleksitas dan sifat BST

Slide menulis O(2log n), maksudnya log berbasis 2. Traversing In-Order pada BST menghasilkan data terurut. Pada balanced BST, pencarian setara binary search pada array terurut, sedangkan insert dan delete lebih cepat daripada pada array terurut. Pada unbalanced BST (misalnya tree miring seperti linked list) kinerja turun menjadi O(n).

2. Binary Heap

Binary Heap adalah complete binary tree yang memenuhi heap property:
Max-heap: nilai tiap node ≥ nilai anak-anaknya (terbesar di root).
Min-heap: nilai tiap node ≤ nilai anak-anaknya (terkecil di root).
Bisa dipakai untuk priority queue (min-heap), prioritas tertinggi ada di root.

Pembentukan Binary Heap (Heapify)

Data 3, 9, 2, 1, 4, 5 (n = 6) belum memenuhi max-heap, maka dilakukan heapify: memperbaiki heap property dari bawah ke atas.

Langkah: (1) mulai dari internal node bukan root terakhir, yaitu posisi (n/2) − 1. (2) Cek anak kiri dan kanan; kalau ada yang lebih besar dari parent, tukar dengan anak terbesar. (3) Ulangi sampai seluruh subtree memenuhi syarat. Untuk n = 6 iterasinya node 2, 1, 0.
def heapify(arr, n, i):
    largest = i
    l = 2*i + 1
    r = 2*i + 2
    if l < n and arr[l] > arr[largest]:
        largest = l
    if r < n and arr[r] > arr[largest]:
        largest = r
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)

Fungsi ini menganggap node i mungkin lebih kecil dari anaknya. Ia mencari yang terbesar di antara i, anak kiri, dan anak kanan (dengan syarat indeks anak masih di dalam n). Kalau ternyata bukan i yang terbesar, nilai ditukar lalu fungsi memanggil dirinya sendiri pada posisi baru supaya perbaikan terus turun ke bawah.

Contoh slide: 3 9 2 1 4 5. Contoh soal slide: 1 3 5 4 6 13 10 9 8 15 17 (hasilnya max-heap yang sama dengan list contoh di atas).

Operasi Insert (percolate up)

(1) Tambahkan elemen di posisi terakhir (paling bawah kanan). (2) Bandingkan dengan parent; kalau elemen baru lebih besar, tukar. (3) Naik terus sampai parent ≥ elemen atau sudah di root. Contoh slide: heap [17, 15, 13, 9, 6, 5, 10, 4, 8, 3, 1], insert 12 menjadi [17, 15, 13, 9, 6, 12, 10, 4, 8, 3, 1, 5].
Heap awal: 17 15 13 9 6 5 10 4 8 3 1. Ganti nilai yang di-insert, misalnya 12 atau 20.

Operasi Delete (heapify down)

(1) Simpan nilai root bila perlu di-return. (2) Ganti root dengan elemen terakhir (paling bawah kanan). (3) Kurangi ukuran heap. (4) Heapify ke bawah dari root: bandingkan dengan kedua anak, tukar dengan anak yang lebih besar jika melanggar, teruskan sampai terpenuhi. Contoh slide: hapus 17, hasil akhir [15, 9, 13, 8, 6, 12, 10, 4, 5, 3, 1].
Heap awal: 17 15 13 9 6 12 10 4 8 3 1 5. Menghapus root (17).

Heapsort

Mengurutkan list memakai heap, versi optimal dari selection sort. Langkah: (1) bentuk max-heap. (2) Tukar root (terbesar) dengan elemen terakhir. (3) Kecilkan ukuran heap (elemen terakhir sudah terurut). (4) Heapify dari elemen pertama. (5) Ulangi sampai urut.

TahapKompleksitas
Build heapO(n)
Heapify per elemenO(log n)
Total HeapsortO(n log n)
# ilustrasi (bukan dari slide), memakai heapify di atas
def heapsort(arr):
    n = len(arr)
    for i in range(n//2 - 1, -1, -1):   # bentuk max-heap
        heapify(arr, n, i)
    for end in range(n-1, 0, -1):
        arr[0], arr[end] = arr[end], arr[0]   # root ke posisi akhir
        heapify(arr, end, 0)                  # perbaiki heap yang mengecil
Kotak hijau pada array = bagian yang sudah terurut. Slide diakhiri dengan [5, 4, 2, 3, 8, 9, 10] menjadi [2, 3, 4, 5, 8, 9, 10].

3. Priority Queue dan Priority Heap

Priority Queue adalah antrean yang tiap datanya punya nilai prioritas. Yang keluar pertama bukan berdasarkan posisinya, melainkan prioritas tertinggi. Aturan slide: semakin kecil angkanya, semakin tinggi prioritasnya (1 = tertinggi). Prioritas sama: sesuai urutan masuk. Operasi: enqueue, dequeue, front, clear, empty, full.

Contoh pemakaian: antrean program user vs system/kernel, pesawat yang akan mendarat (rute, jenis penerbangan, bahan bakar), kendaraan di jalan raya (jenis yang harus didahulukan), pemesanan ojol (pelanggan platinum lebih diprioritaskan).

Kode: Priority Queue Unsorted (List)

class PriorityQueueUnsorted:
    def __init__(self):
        self.queue = []
    def is_empty(self):
        return len(self.queue) == 0
    def enqueue(self, item, priority):
        self.queue.append((item, priority))              # O(1)
    def _idx_tertinggi(self):                             # angka terkecil = prioritas tertinggi
        idx = 0
        for i in range(1, len(self.queue)):
            if self.queue[i][1] < self.queue[idx][1]:
                idx = i
        return idx
    def dequeue(self):
        if self.is_empty():
            raise IndexError("Dequeue from an empty priority queue")
        item, priority = self.queue.pop(self._idx_tertinggi())   # O(n)
        return item
    def peek(self):
        if self.is_empty():
            raise IndexError("Peek from an empty priority queue")
        return self.queue[self._idx_tertinggi()][0]              # O(n)
    def cetak(self):
        for x in self.queue:
            print(x)

Enqueue cukup menambah pasangan (item, prioritas) di belakang list. Dequeue dan peek sama-sama mencari indeks data dengan angka prioritas terkecil lewat satu perulangan, lalu dequeue mengeluarkannya dengan pop(index). Catatan: di slide, dequeue memakai tanda > (mencari angka terbesar) padahal peek memakai <, dan cetak() mulai dari index 1 sehingga elemen pertama terlewat. Di versi di atas sudah saya samakan mengikuti aturan “angka kecil = prioritas tinggi”.

Kode: versi Sorted (ubah enqueue)

def enqueue(self, item, priority):
    new_element = (item, priority)
    for i in range(len(self.queue)):
        if self.queue[i][1] > priority:      # sisipkan sebelum yang prioritasnya lebih rendah
            self.queue.insert(i, new_element)
            return
    self.queue.append(new_element)          # prioritas terendah: di belakang
# dequeue dan peek memakai self.queue.pop(0)[0] atau self.queue[0][0]

Pada versi sorted hanya enqueue yang berubah: ia mencari elemen pertama yang prioritasnya lebih rendah (angkanya lebih besar), menyisipkan data baru tepat di depannya, dan kalau tidak ada, menaruhnya di belakang. Dequeue dan peek jadi sederhana karena data prioritas tertinggi selalu di index 0. (Slide memakai < di baris perbandingan, yang berarti angka besar = prioritas tinggi; di sini disesuaikan dengan aturan angka kecil.)

Priority Queue dengan Heap Tree

Priority queue bisa memakai heap tree: prioritas kecil dianggap penting → min-heap; prioritas besar dianggap penting → max-heap. Elemen prioritas tertinggi selalu di root. Tiap data disimpan sebagai pasangan (item, priority) dan heap property diperiksa berdasarkan priority. Min-heap: parent selalu berprioritas lebih tinggi atau sama dengan anak-anaknya.
